# portal-build

The build tooling for industREAL HMI applications, published to GHCR:

- `ghcr.io/industreal-tech/portal-build` builds an application on your machine (Docker or Podman).
  Your AI client runs it with the command the industREAL MCP build step gives.
- `ghcr.io/industreal-tech/hmi-app-base` is the base image every application runs on.

Exported from the industREAL codegen repository; changes go there, not here.
